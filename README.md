# Дайындық — НИШ және БИЛ

НИШ (Назарбаев Зияткерлік мектептері) және БИЛ (Білім-инновация лицейлері) емтихандарына дайындалатын оқушыларға арналған платформа.

## Іске қосу

Құрастыру қадамы жоқ: `index.html` файлын браузерде ашсаңыз болды, немесе:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Құрылымы

- `index.html`: беттің қаңқасы
- `styles.css`: дизайн (ашық күлгін, бургунди және оливковый жасыл түстер)
- `app.js`: беттер, маршрутизация, тест логикасы, прогресс
- `data/tasks.js`: барлық тапсырмалар
- `data/config.js`: баптаулар (мұғалімнің Google Sheets сілтемесі)
- `teacher/`: мұғалімге арналған Google Sheets скрипті және орнату нұсқаулығы

## Бөлімдер

- **НИШ**, қазақша / орысша: Математика, Сандық сипаттамалар, Жаратылыстану, Қазақ тілі, Орыс тілі, Ағылшын тілі
- **БИЛ**, қазақша: Қазақ тілі, Математика, Логика

## Тапсырма қосу

`data/tasks.js` ішіндегі керекті пәннің `questions` массивіне жаңа объект қосыңыз:

```js
{ q: "Сұрақ", options: ["A", "B", "C", "D"], answer: 1, explain: "Түсіндірме" }
```

`answer` деген дұрыс нұсқаның нөмірі. Санау 0-ден басталады.

## Мұғалімге нәтижелерді жіберу

Оқушылардың ҮБС нәтижелері мен күнделікті мақсаттарын мұғалім Google Sheets-те көре алады. Орнату нұсқаулығы: [`teacher/README.md`](teacher/README.md). Скрипт сілтемесін `data/config.js` ішіндегі `teacherSheetUrl` жолына қойыңыз. Ол бос тұрса, бұл мүмкіндік сайтта көрінбейді.

## Жаңартқанда

Браузер ескі файлдарды есте сақтап қалмауы үшін `index.html` ішіндегі `?v=...` нөмірін әр жаңартқан сайын өзгертіңіз (мысалы, күн мен уақыт: `?v=202611261630`).
